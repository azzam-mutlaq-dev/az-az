# az-az

A TypeScript/React web interface experiment inspired by the visual language of an Azure-style live website.

## What is here

- A Vite-powered React frontend.
- A small Node/Express server entry point.
- TypeScript source shared between client and server.
- Tailwind CSS and Radix UI components.
- A development setup with formatting and type-check scripts.

This repository is an experimental reconstruction/interface study. It is not an official Microsoft or Azure product and should not be represented as one.

## Technology

- TypeScript
- React
- Vite
- Node.js and Express
- Tailwind CSS
- Radix UI

## Local development

Requirements: Node.js and pnpm.

```bash
pnpm install
pnpm dev
```

Useful checks:

```bash
pnpm run check
pnpm run build
```

## Status

Experimental. The repository is suitable for continued UI and frontend engineering work; production readiness, deployment configuration, and third-party service integration are not established by the current codebase.
